# Posting times for a Nauru audience (DRAFT v1)

Nauru is **UTC+12** all year (no daylight saving). 19:30 in Nauru = 07:30 UTC the same calendar day. Check that the Facebook Page / Instagram account timezone is set correctly before scheduling anything.

**Status of this schedule: UNVERIFIED hypotheses.** No Nauru-specific engagement data has been collected yet. The slots below are generic "people check their phone before work, at lunch, and after work/dinner" guesses to be *tested*, not facts. They become evidence only after the learning log below has data.

## Starting test slots (local Nauru time → UTC)
| Slot | Nauru (UTC+12) | UTC | Use for | Basis |
|---|---|---|---|---|

| B | 12:30 | 00:30 same day | Reels, tips | UNVERIFIED (generic lunch break) |

Rule: post new listings in slot C for the first 2 weeks, but alternate B and C on different listings so there is something to compare. Do not post two listings in the same hour.

Sunday is rest/review (see weekly routine); no listing posts.
